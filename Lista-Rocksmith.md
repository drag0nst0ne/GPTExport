Para tocar **"Product of a Murderer"** e **"Ohioisonfire"** do *Of Mice & Men*, você vai querer um som bem agressivo, definido, com bastante presença e **sem excesso de ruído**. Ambos os sons são característicos do **metalcore moderno**, então vou te sugerir uma cadeia de pedais virtuais ideal para usar no **AmpliTube** (ou plugins semelhantes como Guitar Rig ou ToneLib GFX).

### Pedais indicados para esses sons:

#### 1. Noise Gate

- **Evita ruídos** entre as palhetadas rápidas e breaks.

- Virtual: `Noise Gate` / `Noise Filter`

- **Coloque como o primeiro pedal** da cadeia.

#### 2. Tube Screamer (Overdrive, como boost)

- **Função:** Dá mais ataque e definição antes da distorção.

- Use com ganho baixo, volume alto (clean boost).

- Virtual: `OverScream` (AmpliTube) ou qualquer simulação do **Ibanez TS9/TS808**.

#### 3. Distortion

- Essencial para o peso. Busque uma distorção de alta-gain, mas controlada.

- Virtual: `Metal Dist` (estilo Boss Metal Zone) ou `Hi-Gain Amp Sim`.

- Ou use o **canal drive de um amplificador** tipo Peavey 6505 ou ENGL Powerball (muito usado no metalcore).

#### 4. EQ

- Afine o timbre: reduza médios se quiser soar mais “djenty”, ou aumente um pouco os médios/agudos para soar mais *core* tradicional.

- Virtual: `Graphic EQ` ou `Parametric EQ`

#### 5. Reverb (leve ou nenhum)

- Para solos ou partes melódicas. Use pouco, pois o som da banda é mais seco/preciso.

- Virtual: `Room Reverb` ou `Plate Reverb` com mix baixo (~10–15%)

### Cadeia sugerida (ordem dos pedais):

```
Guitarra → Noise Gate → Tube Screamer (boost) → Distortion / Amp Hi-Gain → EQ → Reverb → Saída
```

### Dicas extras:

- **Afinação:** Essas músicas costumam usar afinações baixas (como Drop C ou Drop B). Use um plugin como **"Pitch Shifter"** se for tocar com afinação padrão por enquanto.

- **Palm mute e precisão:** Use esse preset para treinar palhetada alternada com muting — base fundamental no som deles.

- **Cabinet Simulation (IR):** Use um **impulse response (IR)** de caixas 4x12 com microfone SM57 para soar mais profissional.
